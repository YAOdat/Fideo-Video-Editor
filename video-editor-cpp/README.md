# Video Editor (C++)

A cross-platform desktop video editor written in C++.

## Planned Features
- Import video
- Add/overlay sound
- Smooth sound entry and exit (fade in/out)
- Video transitions
- Masking
- Watermark overlay

## Project Structure
- `src/` - Source files
- `include/` - Header files
- `assets/` - Sample media, icons, etc.
- `CMakeLists.txt` - Build configuration
